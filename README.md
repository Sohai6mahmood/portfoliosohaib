# AIML Professional Portfolio - Sohaib Mahmood

Welcome to the repository for my Artificial Intelligence and Machine Learning Professional Portfolio, developed during my coursework at Indiana Wesleyan University. 

This repository contains the source code for a fully responsive, modern web portfolio hosted on GitHub Pages, featuring dark mode aesthetics, glassmorphism UI elements, and smooth scroll animations.

## Project Version History & Iterations

### Version 1: Foundation and Initial Setup
- **Objective:** Create a professional, shareable online platform to showcase AI/ML competencies.
- **Actions Taken:** 
  - Built the core architecture using Vanilla HTML, CSS, and JavaScript to ensure fast, lightweight deployment on GitHub Pages.
  - Implemented a "Professional Bio" and "Personal Value Proposition" tailored to the tech industry.
  - Drafted 5 AI/ML specific artifact placeholders.
- **Grader Feedback Received:** Requested exact rubric template headings in correct order and specific AI/ML skill examples. *(Addressed retroactively in Version 3).*

### Version 2: Artifact 2 (Computer Vision)
- **Objective:** Provide a deep dive into an authentic, tangible class activity demonstrating deep learning skills.
- **Actions Taken:**
  - Expanded the Computer Vision Defect Detection artifact.
  - Created a Python script (`defect_detection_model.py`) as initial code evidence.
- **Grader Feedback Received:** Requested verifiable evidence for the 96% accuracy claim (e.g., confusion matrix or results table). *(Addressed retroactively in Version 3).*

### Version 3: Artifact 3 (NLP Chatbot) & Comprehensive Revisions
- **Objective:** Showcase a new skill (Natural Language Processing) while achieving a perfect 30/30 score by aggressively applying all previous instructor feedback.
- **Actions Taken for Artifact 3:**
  - Added the NLP Customer Support Chatbot artifact.
  - Created `nlp_chatbot_evidence.html` containing a confusion matrix, accuracy metrics, and concrete before-and-after data pipeline transformations.
- **Retroactive Fixes Applied:**
  - **Artifact 1 (Customer Churn):** Added explicit `Introduction` and `Description` headings. Integrated specific skills like `pandas`, `SMOTE`, and `XGBoost`.
  - **Artifact 2 (Computer Vision):** Created `cv_defect_evidence.html` to provide the specific confusion matrix and results table requested by the grader for the 96% accuracy claim.

### Version 4: Artifact 4 (Sales Forecasting Dashboard)
- **Objective:** Showcase data analysis and business intelligence translation by predicting time-series data.
- **Actions Taken:**
  - Configured Artifact 4 on the live portfolio with all precise rubric headings (`Introduction`, `Description`, etc.).
  - Created `sales_forecasting_evidence.html` as the verifiable supporting file, documenting tangible metrics like MAPE (8.4%) and RMSE, along with actual Python `statsmodels` code implementation.
