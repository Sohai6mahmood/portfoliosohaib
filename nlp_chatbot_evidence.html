NLP Customer Support Chatbot - Evaluation Report

1. Model Evaluation Metrics

The Support Vector Machine (SVM) text classifier was trained on 10,000 historical support tickets and evaluated on a holdout test set of 2,000 queries. The model routes queries to four main departments: Billing, Technical, Sales, and Returns.

Metric Score Description
Overall Accuracy 94.2% Percentage of correctly routed queries across all departments.
Macro F1-Score 0.93 Harmonic mean of precision and recall, balanced across classes.
